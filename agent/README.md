<p align="center"><strong>CloudMateHub Agent</strong></p>

The CloudMateHub is a lightweight software component that runs the device and provide communication between the device and CloudMateHub's server. Its main role is to provide a reserve SSH server always connected to the CloudMateHub server, allowing SSH connections to be established to the device even when it is behind a firewall or NAT.

## Features

- **Secure Communication:** The agent establishes encrypted connections between remote devices and the CloudMateHub server, ensuring data confidentiality and integrity during communication.

- **Device Registration:** Upon installation on a new device, the agent registers it with the CloudMateHub server, making it accessible and manageable from the web interface.

- **Authentication and Access Control:** The agent handles user authentication, allowing administrators to enforce access control based on user credentials and defined permissions.

- **Session Management:** The agent manages SSH sessions initiated by users, providing secure remote access to registered devices through the CloudMateHub web interface.

- **Heartbeat and Health Checks:** The agent sends regular heartbeat signals to the CloudMateHub server, indicating its status and health, facilitating device availability monitoring.
