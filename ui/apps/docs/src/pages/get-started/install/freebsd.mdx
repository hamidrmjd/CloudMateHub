# Installing on FreeBSD

FreeBSD is supported, but not by the install script. If you run it there, the installer stops and
points you here:

> Automatic installation is not supported on FreeBSD. Please refer to the CloudMateHub port at
> https://github.com/shellhub-io/ports

## The port

The port lives in [github.com/shellhub-io/ports](https://github.com/shellhub-io/ports), not in
the official FreeBSD ports tree. There is no binary package — you build from source.

```bash
$ git clone https://github.com/shellhub-io/ports.git /usr/local/cloudmatehub-ports
$ cd /usr/local/cloudmatehub-ports/cloudmatehub
$ make install clean
```

The port pulls Go as a build dependency and installs the agent as an `rc.d` service.

## Configuration

In `/etc/rc.conf`:

```bash
cloudmatehub_enable="YES"
cloudmatehub_server_address="https://cloud.shellhub.io"
cloudmatehub_tenant_id="<your-tenant-id>"
```

Both the server address and the tenant ID are required — the `rc.d` script validates them at
startup and exits with an error if either is missing.

The script names the namespace by its tenant ID and has no setting for a provisioning key, so a
FreeBSD device always lands pending until somebody accepts it.

The agent generates a private key on first run and stores it at `cloudmatehub_private_key`, which
defaults to `/usr/local/etc/shellhub.key`. That key is the device's identity: delete it and the
device re-registers as a new one, so it belongs on persistent storage.

## Managing the service

```bash
$ service cloudmatehub start
$ service cloudmatehub stop
$ service cloudmatehub restart
$ service cloudmatehub status
```

## Updating

The port has no package manager behind it, so an update is a rebuild:

```bash
$ cd /usr/local/cloudmatehub-ports && git pull
$ cd cloudmatehub
$ make deinstall
$ make install clean
$ service cloudmatehub restart
```
